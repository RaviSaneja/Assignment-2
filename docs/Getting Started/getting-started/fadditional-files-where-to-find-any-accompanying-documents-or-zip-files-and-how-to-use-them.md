## **Additional Files**

The Intelligent Clinical Support System (ICSS) is accompanied by **22 supporting files**, comprising 16 interface designs, three illustrated storyboards, a system architecture diagram, a system flowchart and a written report. These files provide supporting evidence of the project's design decisions, intended functionality, human–AI interactions and development scope.

### **4. Instructions for accessing and using the files**

1. Download and extract the accompanying ZIP archive once packaged.
2. Read the project report to understand the objectives, design rationale and scope.
3. Open the system architecture and flowchart to understand the overall workflow.
4. Review the storyboards to understand the healthcare scenarios and intended human–AI interactions.
5. Inspect the numbered interface designs to replay the patient and healthcare professional journeys.

The PNG and JPG files can be opened using any standard image viewer or web browser. The DOCX report can be accessed using Microsoft Word or a compatible document reader. No additional software dependencies or API credentials are required to inspect the visual artefacts.

### **5. File availability and limitations**

All 22 supporting files have been supplied in this conversation. However, an accompanying ZIP archive, README file, executable source code and interactive prototype link have not yet been provided.

The supporting materials demonstrate the project design and intended interactions rather than verified operational AI functionality.
