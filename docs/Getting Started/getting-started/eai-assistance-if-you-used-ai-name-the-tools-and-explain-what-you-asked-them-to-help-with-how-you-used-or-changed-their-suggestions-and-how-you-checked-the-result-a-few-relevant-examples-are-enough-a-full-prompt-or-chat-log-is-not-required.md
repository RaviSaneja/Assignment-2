## **AI Assistance**

I used **OpenAI ChatGPT** as an AI-assisted tool to support the review, organisation and documentation of the Intelligent Clinical Support System (ICSS). AI assistance helped identify design inconsistencies, clarify technical concepts, structure the project report and distinguish demonstrated prototype functionality from proposed capabilities.

### **1. AI tools and their application**

| AI tool        | Purpose                                                                              |
| -------------- | ------------------------------------------------------------------------------------ |
| OpenAI ChatGPT | Project documentation, design analysis, technical explanations and report refinement |
| OpenAI ChatGPT | Reviewing interface designs, system architecture, storyboards and flowchart          |
| OpenAI ChatGPT | Identifying design limitations, inconsistencies and potential improvements           |

### **2. Examples of AI assistance**

| Area                                  | What I asked AI to help with                                                              | How the suggestions were used or adapted                                                                                           | How the results were checked                                                                       |
| ------------------------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **System architecture**               | Analyse the relationships between questionnaires, LLM, RAG and clinical decision support. | Used the analysis to organise the system components and clarify their intended responsibilities.                                   | Compared the analysis against the original architecture and design rationale.                      |
| **Interface design review**           | Analyse the 16 interface designs and identify their functionality.                        | Used the extracted features to organise functional requirements and interaction workflows.                                         | Compared the extracted functionality against the supplied interface designs.                       |

### **3. Example of reviewing and adapting AI suggestions**

During the review of the project materials, AI identified an inconsistency between the system architecture, which described basic RAG as implemented, and the written report, which described RAG as proposed.

The documentation was therefore refined to distinguish visual prototype functionality from unverified technical implementation. This prevented the report from presenting proposed functionality as completed work.

AI also identified that the original flowchart positioned insurance and emergency assistance as sequential stages. A suggested improvement was to make insurance optional and emergency assistance accessible throughout the patient journey. These recommendations remain proposed design improvements unless incorporated into a revised flowchart.

### **4. Verification and responsible use**

AI-generated suggestions were treated as supporting material rather than automatically accepted as correct. The review process included:

- Cross-referencing AI-generated descriptions against the original project artefacts.
- Identifying unsupported implementation and testing claims.
- Distinguishing demonstrated functionality from proposed technical capabilities.
- Reviewing consistency between the architecture, interfaces, storyboards and written report.
- Maintaining professional clinical oversight and appropriate AI safety boundaries.
- Avoiding fabricated testing results, development dates and commit references.

### **5. Limitations of AI assistance**

AI-generated content does not constitute evidence of successful technical implementation, clinical accuracy, regulatory compliance or completed user testing. AI suggestions require human review and independent verification before being incorporated into the final system.

The use of AI as a project development and documentation assistant is also distinct from the proposed use of LLM and RAG technologies within ICSS itself.
